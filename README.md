# 🎂 Priya Birthday Website — Page by Page

This version is intentionally **not a scrolling birthday website**. Each section is a separate full-screen page, opened by clicking a button.

## 🔐 Birthday Login
The first page asks for Priya's birthday.

**Correct birthday: 13 August 2004**

This is a fun browser-side birthday gate, not real security.

## 🎁 Page flow
1. Birthday login
2. Welcome
3. Personal birthday message
4. Reasons why Priya is special
5. Interactive wish
6. Memory wall
7. Wishes for the year ahead
8. Final birthday celebration

Every important click triggers confetti.

## 📸 Add Priya's photos
Put these files inside `assets/memories/`:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

The memory page automatically displays them.

## 🚀 GitHub Pages
Upload the project to a GitHub repository, then:
**Settings → Pages → Deploy from a branch → main → / (root) → Save**
